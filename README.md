## 📖 Overview

**Drift-Sense** solves a critical, multi-million dollar problem in the semiconductor fabrication pipeline: **Navigation-Error Recovery**. 

When Scanning Electron Microscopes (SEMs) inspect wafers for defects, stage drift and coordinate inaccuracies cause the microscope to look at the wrong region. The goal of this project is to take a **high-resolution reference pattern** (1000x1000 px @ 1 nm/px) and precisely locate its true (x,y) center inside a **noisy, zoomed-out search image** (1000x1000 px @ 10 nm/px).

### 🚨 The "Periodic Ambiguity" Problem
Over 30% of modern DRAM and FinFET layouts are purely periodic. Traditional template matching (like pure NCC) fails catastrophically because repeating semiconductor structures yield mathematically identical matching peaks. 

### ✨ Our Solution: The v9.0 Hybrid Engine
Drift-Sense tackles this by pairing a mathematically infallible **Classical Computer Vision Engine** (providing guaranteed safety) with a highly-specialized **Squeeze-and-Excitation Siamese Neural Network** (which acts strictly as a tie-breaker when periodicity confuses the classical engine).

---

## 🧠 Core Architecture & Innovations

Our pipeline operates in a rigorous **5-Stage Precision Sequence**:

1. **🛡️ Safety-Net Baseline NCC:** We compute a baseline 10x downsampled match to guarantee a worst-case anchor. **Our system is mathematically guaranteed to never perform worse than the baseline.**
2. **🏗️ Zone Boundary Constraints:** A custom classical algorithm detects macro-level "mat" and "strip" grids in the search image using bandpass-filtered intensity derivatives, restricting periodic repeats to the correct die cell.
3. **📊 Multi-Scale Dual-Domain Fusion:** Cross-scale consistency voting (combining standard intensity with Sobel gradient-magnitude) aggressively filters out extreme SEM detector noise.
4. **🤖 AI Siamese Disambiguation:** When candidates have tied scores, our lightweight (~5MB) **MediumEncoder** activates. Using Squeeze-and-Excitation (SE) Attention blocks, it ignores redundant periodic noise and ranks candidates based on unique structural boundaries and defect fingerprints.
5. **🎯 Sub-Pixel Aliasing Refinement:** Instead of downsampling the 1nm/px reference (which destroys data), we analyze the unique sub-pixel Moiré/aliasing artifacts generated by the 10x resolution gap using Hann-windowed phase cross-correlation. This pushes accuracy to `<1px` error levels.

## 🚀 Installation & Deployment

### 1. Clone & Setup Environment
```bash
git clone https://github.com/JayanthSairam467/Semicon-Drift-Sense.git
cd Semicon-Drift-Sense

# Create a virtual environment (Recommended)
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Running Inference (For Judges)
To test a single image pair, run the main inference script. The script is highly decoupled, dependency-light, and returns the precise center coordinates:

```bash
python localize.py --reference path/to/reference.png --search path/to/search.png
```
**Output Format:**
```text
x.xx,y.yy
```
*(You can also use the `--json` flag to receive verbose output including confidence scores, inference time in milliseconds, and the exact pipeline method utilized).*

## 💻 Custom AI Training (Optional)
If you wish to train the Siamese Ranker from scratch on your own proprietary dataset:

1. **Generate Hard-Negative Triplets:**
   ```bash
   python generate_triplets.py --num-triplets 4000 --output my_training_data
   ```
2. **Execute Offline Training:**
   ```bash
   python train_offline.py --train-dir my_training_data --epochs 30
   ```
*(The pipeline automatically exports the best weights to the `/weights` directory for immediate use by `localize.py`).*
